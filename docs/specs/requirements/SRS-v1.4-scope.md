# SRS-MYCC-001 v1.4 — 编译器范围收敛修订

日期：2026-10-26　实施版本：mycc 0.3.0　变更单：**CR-SCOPE-001**。

本修订以用户确认的 [范围说明](../../guides/scope.md) 为依据。范围说明已先独立提交 `989e49d`，随后开始程序修改。旧 SRS v1.2、CPU21 v1.3 修订和历史验收保留；当前基线为旧通用需求及本修订，CPU21 专用要求仅约束显式外部适配。冲突项以本修订为准。

## 1. 定位与边界

产品输入为一个受限 C 源文件和 ISA 配置，主要输出为 GNU RISC-V 汇编、源码诊断和 Lowering 说明。支持范围仍为既有 int/int*/一维数组、函数、控制流、运算符和 sizeof，不新增语言功能。

主流程不要求板卡、最终链接地址、MMIO、QEMU 或 Vivado。函数 ABI、栈帧和缺失算术指令的软件回退继续属于编译器。启动、最终内存布局、外设、ROM 镜像及板卡执行验证属于外部适配。

完整扫雷、RARS 输出格式、自动下载 FPGA 和调试器继续暂缓。当前 GNU .s 不宣称 RARS 兼容，原扫雷继续由既有 GCC 流程构建。

| 编号/组 | v1.4 生效要求 |

| FR-111/112/114、CN-02 | CLI/GUI 默认 PF-01；已有合法预设/组可选。cpu21 是 ISA 参考集合，单独选取不会激活板卡 ABI。显式外部适配可另行检查硬件能力 |

| FR-901..909、FR-911、FR-919/920 | 保留薄工作台：编辑、ISA、编译/取消、结果查看、导出和诊断定位，继续共用核心 API |
| FR-910/912 | GUI 的 QEMU 运行、固件构建和 ELF lint 从主界面移除；对应命令保留在外部工具中，帮助菜单说明用法 |

## 3. 对 CPU21 v1.3 修订的覆盖关系

- 覆盖“默认 CPU21/cpu21”：0.3.0 主程序恢复 generic/PF-01，CPU21 为显式外部适配。
- 覆盖“主界面固定板卡、屏蔽其他 ISA”：界面仅选择合法 ISA，不作板卡限制，也不显示地址配置。
- 保留 CPU21 的硬件事实、Harvard 初始化、VGA/字形限制、栈保护、ROM 导出及只读 RTL 验证，但实现归入 `adapters/cpu21/`。
- CPU21 适配仍可通过 `tools.build --target cpu21` 或兼容 `mycc --target cpu21` 使用；不回写原硬件工程。

## 4. 本阶段验收

| 编号 | 要求 | 验证落点 |
|---|---|---|
| SC-CORE-01 | 函数/循环/算术示例生成 GNU 汇编，真实汇编成功；外部环境可验证执行 | bench/compiler_demo.c、test_scope、可选 RTL |
| SC-CORE-02 | 同一源码在有/无 mul 下选择不同实现，语言分析相同，说明原因；可选执行结果一致 | test_sc_core_02、compiler_demo 两组 RTL |
| SC-CORE-03 | 错误定位准确；失败不覆盖成功输出；非法 ISA 提供建议 | test_sc_core_03 及既有故障测试 |
| AC-16 | 普通 CLI 编译不导入适配层、不需要外部工具；核心不包含板卡事实，GUI 不创建外部进程 | 新进程导入断言、静态检查、offscreen 控件测试 |
| AC-17 | 外部适配迁移后可显式回归，旧证据不被当作新版本结果 | CPU21 正式固件回归、新版本独立报告 |

外部执行环境缺失时应报告未验证，不能因汇编成功而声称执行通过。未实际测量的原性能等指标继续标为未验证，不因范围调整自动通过。
